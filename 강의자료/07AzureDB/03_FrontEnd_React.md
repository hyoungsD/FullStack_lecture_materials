# FrontEnd 구성 (React - node.js - scottdb)

---

> 새로운 Terminal 오픈

### vite-react 구성
npm create vite@latest dept-fe -- --template react
  ESLint

cd dept-fe
npm install
npm run dev

```
- Shortcuts
  press r + enter to restart the server
  press u + enter to show server url
  press o + enter to open in browser
  press c + enter to clear console
  press q + enter to quit
```
